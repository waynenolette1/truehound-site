Free template

The access review template your auditor can follow.

One sheet per system. It records what auditors commonly ask for: the user list as of a date, a named reviewer, a decision and reason for every account, and proof that removals held. Download it as a CSV for your spreadsheet, or a PDF to print and sign. No email needed.

The header, once per system

Company
Legal name, as on the audit report.
System reviewed
One system per sheet, e.g. GitHub organization acme.
System owner
The person accountable for access to this system.
Review period
For example Q4 2026 (1 Oct to 31 Dec 2026).
Population as of
Date and time the user list was pulled. Pull it from the system itself.
How the list was pulled
Export, admin page or API, with the path, so the auditor can repeat it.
Reviewer
Name and role. Not the person whose access is being reviewed.
Completed on
Date the last decision was made and signed off.

Using it

  1. Pull each system's user list on the same day and note how you pulled it.
  2. Mark who left using your HR list or identity provider, and mark every admin.
  3. Decide every row. Write a reason for every keep on an admin and every change.
  4. Make the changes, then pull the list again and record that they held.
  5. Sign off, date it, and file it with your audit evidence.
