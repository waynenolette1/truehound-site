AI agent control

Your AI agents already have access. Now you can prove what they did.

Coding agents call tools, run commands and open websites with your engineers' keys. Truehound asks before each call, answers allow, ask or deny by your rules, and keeps every call on the record with its secrets stripped out.

Two weeks of agent tool calls

Sample workspace: Acme. Each call went through the hook's own redaction and the server's own rule check, in your browser, against Acme's three rules.

What makes it work

  1. 01

    An open hook you can read

    The hook is one file with no dependencies. Read every line before you install it. It sends a short summary of each call to your workspace and turns the answer into the client's own hook output; nothing is rerouted.

    Read the hook script
  2. 02

    A check before every action

    The client asks before each tool call. Your rules answer allow, ask or deny by server, tool, person, group, input pattern or website. The request gives up after 250 ms; a workspace or a rule decides whether a call that cannot be checked runs or stops.

  3. 03

    Five AI clients

    Claude Code, Cursor, Windsurf, VS Code Copilot and Codex, each through its own documented hook, installed with one command or deployed by your device manager.

  4. 04

    Rules drafted for you, replayed on 30 days

    Truehound drafts rules from the calls it has already seen, with Claude on your own Anthropic key or with its built-in rules. Each draft is replayed on the last 30 days of calls so you see what it would have stopped, and nothing applies until an admin approves it.

  5. 05

    Secrets stripped on the laptop

    API keys, tokens, passwords and private keys are replaced with [REDACTED] on the engineer's machine before anything is sent, and the server runs the same check again before it stores a line.

And every AI key and agent, with an owner

  • AI key inventory

    OpenAI and Anthropic API keys, projects and service accounts, and GitHub Copilot seats, read from each provider's admin API, with the owner and the last use where the provider reports one.

  • Agents and MCP servers

    MCP servers and agent tokens on the gateway, logins to AI apps, AI bots and OAuth grants to AI apps, each with an owner. Suspend one, or use the kill switch.

  • Which apps people use

    Discovery lists the apps people log in to, how they got in, what each can reach, and whether it is allowed.

  • Take it back, then prove it

    A revoke is checked by a fresh read of the provider. A key still active after the revoke is shown as still present, not as done.
